#120 fixture: soft width rule replaces R8 local row widening.

args.txt sets --max-cell-width 20. The Notes column's widest atomic token is the code span
`Set-ExecutionPolicy-RemoteSigned` (34 chars), which exceeds the cap.

The Notes column floors at its widest atomic token (34) and the WHOLE column renders at 34 --
header, separator, and every data/continuation row aligned at width 34. The old per-row
effective_width local widening (R8) is gone: columns have one width for every row, so pipes
align on every row. The Command column stays at its planned width (7). This is the exact
behavior #120 Proposal item 4 specifies: "the column itself widens, so pipes align on every
row of the table."

This case is the load-bearing regression that distinguishes the new soft width rule from the
old R8 behavior. AE3's golden encoded the OLD R8 widening and was regenerated under the soft
width rule as part of this change.
