# Paths listed here are SKIPPED by `run-tests.py --idempotency`.
# One repo-relative path per line (forward slashes). Blank lines and lines
# beginning with '#' are ignored. Paths are matched against each sweep
# target's path relative to the repository root.

# The idempotency sweep formats every .md under examples/ and spec/, plus
# every non-KNOWN_FAIL case's input.md, twice, and requires the two passes
# to be byte-identical. A file belongs here ONLY when its non-idempotency
# is a known, tracked limitation of the formatter (e.g. the documented
# `auto`-strategy non-idempotency) rather than a fixture bug -- add a
# comment naming the tracking issue next to any entry you add.
#

# examples/some-file.md    # non-idempotent under auto strategy, tracked in #NNN
