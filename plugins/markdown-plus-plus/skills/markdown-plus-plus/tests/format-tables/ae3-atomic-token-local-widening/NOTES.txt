Golden regenerated under the #120 soft width rule (Proposal item 4), replacing the old R8
per-row local widening. The Detail column now floors at its widest atomic token
(**`Set-ExecutionPolicy`** = 25 chars) and the WHOLE column renders at 25 -- header,
separator, and every data/continuation row aligned at that width. The old behavior widened
only the single continuation row holding the over-width token, leaving the rest of the
column at width 20 with misaligned pipes; the soft width rule gives one width per column so
pipes align on every row. The AE4 and AE7 sub-tables in the same fixture re-flow to their
own soft-width columns as well.

default flags -- is unaffected.
